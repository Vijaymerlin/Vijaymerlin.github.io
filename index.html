Wholesale Order Management Portal

A B2B portal where wholesale customers request products and admins and warehouse staff take each order through approval, payment, picking, packing, shipping and invoicing.

ASP.NET Core MVC (.NET 8) Entity Framework Core SQL Server Role Authorization QuestPDF SMTP Email

  • Shipment creation with tracking updates
