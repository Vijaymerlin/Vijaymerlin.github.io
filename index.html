Wholesale Order Management Portal

A B2B portal where wholesale customers request products and admins and warehouse staff take each order through approval, payment, picking, packing, shipping and invoicing.

ASP.NET Core MVC (.NET 8) Entity Framework Core SQL Server Role Authorization QuestPDF SMTP Email

Key Features

  • Three kinds of users: customers, admins and warehouse staff, each with their own access and dashboard
  • Cart and purchase requests, with an admin approval flow (approve, request changes or reject)

  • Payment recording and approval
  • Pick list generation and completion for the warehouse
  • Packages, package labels and packing slips
  • Shipment creation with tracking updates
  • Invoice generation as PDF, emailed to the customer or downloaded
  • Configurable order settings and automatic document numbering
